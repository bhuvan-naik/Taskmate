# TaskMate – Student Productivity Manager 📚

**TaskMate** is a simple, interactive student productivity web application designed to help students organize their academic tasks, manage deadlines, and keep track of their progress.

The goal of this project is to make everyday academic task management easier through a clean and user-friendly interface.

## ✨ Features

- **Add Tasks:** Create tasks with a title, subject, and deadline.
- **Task Dashboard:** Track total, pending, and completed tasks.
- **Task Completion:** Mark tasks as completed when finished.
- **Task Filtering:** View all tasks, pending tasks, or completed tasks.
- **Dynamic Updates:** Dashboard statistics and task lists update automatically.
- **Empty State:** Displays a message when no tasks are available.

## 🚀 Getting Started

Follow these steps to run TaskMate locally.

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd TaskMate
```

**3. Run the application**

Open `index.html` in your browser, or use the Live Server extension in VS Code.
